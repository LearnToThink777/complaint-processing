# 챌린지 제출 문서 — 금융 민원 처리 에이전트

> 심사용 "정문". 무엇을 만들었고, 챌린지 두 주제에 어떻게 맞닿고, 무엇이 다르며, 어떻게 돌려보는지.
> 상세는 [ARCHITECTURE](ARCHITECTURE.md) · [SKILLS](SKILLS.md) · [DIFFERENTIATION](DIFFERENTIATION.md).

## 1. 개요

**문제.** 시중은행 챗봇은 룰 기반·비개인화·세션 한정 기억·키워드 매칭에 머문다. 금융 분쟁 민원은
사실관계에 근거한 **규정 판정**과, 민원인·감독원이라는 **다른 독자를 위한 서로 다른 설명**, 그리고
소비자가 **다음에 무엇을 할 수 있는지**의 안내가 필요하다.

**접근.** "에이전트가 일하는 콘솔"에서 정말로 LLM이 판단·작문해야 하는 자리만 실제 코드로 뽑아내고,
나머지(사건 생성·원장·상태 전이·기한·완결성 게이트)는 **결정론 상태 기계**로 남겼다. LLM 판단은
**Pydantic 계약(구조화 출력)** 으로 받아 감사·검증 가능하게 했다.

## 2. 챌린지 주제 매핑

### 주제 ① 단계별 멀티 에이전트 기반 금융 분쟁 민원 작성 어시스턴트
- **단계별 자동 생성** — 상태 기계가 접수→검토→여유판정→(재협상)→종결을 순차 프레임으로 생성.
- **유사 판례·상담 사례 검색** — law.go.kr 법령·분쟁조정 결정문 코퍼스 RAG(#3), 일상어 라벨로 어휘 비대칭 해소.
- **역할 분리** — 검토계획(#0)·규정판정(#1)·이중공개(#2)·유사사례(#3)·재협상(#4)로 스킬이 역할별 분리.

### 주제 ② 금융 소비자 권익 보호를 위한 AI 에이전트
- **대응 절차·권리 보호 방안 안내** — 종결 시 사건 원장에 근거한 **소비자 권익 보호 안내(#6)**.
- **신뢰 제고** — 이중 공개·중립성 밸런스·권한 경계(자문만)·출력 검증(Critic).
- **도메인 특화** — 법률(판정·검토계획)·사례(유사사례)·비법률 안내(트리아지 #7) 축.

전체 대조표와 8가지 기존 차별점은 [DIFFERENTIATION](DIFFERENTIATION.md).

## 3. 핵심 차별점 (요약)

1. **권한 경계** — 에이전트는 자문·중재만. 새 기한(#4)·권리 행사(#6)는 권고·안내까지, 확정은 사람.
2. **이중 공개** — 같은 사실을 민원인용(공감)·감독원용(기술)으로 청중별 재작문(#2).
3. **개인화된 근거 기반 안내** — 키워드 매칭이 아니라 사건 원장·RAG에 근거(#0·#3·#6). 위반/무혐의에 따라 안내가 달라짐.
4. **비법률 일반 민원 트리아지(#7)** — 모든 민원을 법률 파이프라인에 밀어넣지 않고 경량 안내로 분기.
5. **결정론 ↔ LLM 분리 + 출력 검증(Critic)** — 감사 가능성·할루시네이션 방어.

## 4. 데모 시나리오

먼저 서버를 띄운다:
```bash
cd C:\Users\alstj\Downloads

uvicorn complaint_processing.api:app --reload      # http://127.0.0.1:8000
```
- **Swagger UI**: http://127.0.0.1:8000/docs — 전 엔드포인트를 "Try it out"으로 실행.
- **콘솔**: http://127.0.0.1:8000/viewer.html — 상단 **⚖ 법률 민원 / 🧭 일반 민원** 토글.

### 시나리오 A — 법률 분쟁 (ELS 불완전판매)
1. viewer에서 **⚖ 법률 민원** (기본). ▶ 재생으로 접수→검토 루프→여유 판정→재협상→종결을 단계별로 관찰.
2. 각 단계에서 **③ 검토 항목**·**② 적용 법률 원장**·**이중 공개(민원인/감독원 뷰 전환)** 확인.
3. 종결 프레임에서 **🛡 소비자 권익 보호 안내(#6)** — 위법계약해지·손해배상·분쟁조정 + 준비 서류·확대 경로.
4. API로도: `GET /api/frames` (또는 `POST /api/cases/run`).

### 시나리오 B — 비법률 일반 민원 (이체한도 문의)
1. viewer에서 **🧭 일반 민원** 토글 → 트랙 배지가 **🧭 일반 안내**로 바뀌고 법률 패널이 숨겨진다.
2. **🧭 일반 안내 패널**: 답변·절차·셀프처리 가능 여부·문의처(규정 판정·원장 없이 경량 종결).
3. API로도: `GET /api/frames?case=general`, `POST /api/skills/general-guidance`.
