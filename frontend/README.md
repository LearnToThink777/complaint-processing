# 금융 민원 처리 — 프론트엔드 (React SPA)

기존 FastAPI 백엔드(`complaint_processing/api.py`)를 **시각화**하는 시연용 프론트엔드입니다.
백엔드 로직은 전혀 바꾸지 않고, 화면에서 새로 도출된 기능(사건 목록·일관성 점수·판정
결과·마이페이지 등)은 백엔드에 얇은 시연 계층(`demo_store.py` / `demo_api.py`)으로만 추가했습니다.

두 개의 화면을 하나의 앱에서 제공합니다.

- **직원 데스크탑 대시보드** — 홈 · 사건접수 · 처리현황 · 이력 · 마이페이지 (좌측 사이드바)
- **민원인 모바일 앱** — 홈 · 민원접수 · 진행현황 · 이력 · 마이페이지 (하단 탭바)

## 시연 실행 (빌드본 — 권장)

빌드 산출물(`complaint_processing/ui/`)이 저장소에 포함되어 있어, **백엔드만 켜면** 바로 열립니다.

```bash
# 저장소 상위(Downloads)에서
python -m uvicorn complaint_processing.api:app --port 8000
```

브라우저에서 접속:

| 화면 | URL |
| --- | --- |
| 시작(선택) | http://127.0.0.1:8000/ui/ |
| 직원 대시보드 | http://127.0.0.1:8000/ui/#/staff |
| 민원인 앱 | http://127.0.0.1:8000/ui/#/app |

> 라이브 API 호출(`/api/*`)이 실패하면 화면은 내장 폴백 데이터로 자동 렌더링됩니다.

## 개발 (핫리로드)

```bash
# 1) 백엔드 (한 터미널)
python -m uvicorn complaint_processing.api:app --port 8000

# 2) 프론트 (다른 터미널)
cd frontend
npm install
npm run dev          # http://localhost:5173/ui/  (/api → 8000 프록시)
```

## 빌드 (배포/시연본 갱신)

```bash
cd frontend
npm run build        # → complaint_processing/ui/ 로 출력
```

빌드 후 uvicorn을 (재)시작하면 FastAPI가 `/ui` 로 서빙합니다.

## 라이브(실제 AI) 실행

목록·이력 등은 즉시 렌더용 **시드 데이터**로 채우고, 핵심 패널에는 **실제 LLM 파이프라인**을 붙였습니다.
기존 백엔드 스킬 엔드포인트(`/api/skills/*`)를 그대로 호출합니다.

- **사건접수** → `⚡ 실제 AI로 검토계획 생성` : 사건 사실관계를 코퍼스(임베딩 RAG)에 질의해 검토 항목을 실제 도출
- **처리현황** → `⚡ 유사사례 실제 검색·분석` (임베딩 RAG) · `⚡ 실제 AI로 이중 공개 생성` (민원인용/감독원용 분리 작문)
- **처리현황** → `🤝 협상·중재 콘솔 열기` : 실데이터 중재 콘솔(`/mediation.html`)로 이동
- provider 셀렉터로 **GPT-5 mini ↔ Gemini(더 빠름) ↔ GPT-5 nano** 전환

> ⚠️ **왜 패널별 단발 호출인가**: GPT-5 계열은 reasoning 모델이라 구조화 호출 1건이 ~20초.
> 전체 파이프라인(16회 연쇄)을 한 번에 실제로 돌리면 5~10분이 걸려 시연에 부적합합니다.
> 그래서 화면은 시드로 즉시 렌더하고, 버튼을 눌렀을 때만 해당 패널을 실제 LLM으로 채웁니다.
> 실제 LLM 키는 `.env`(`MLAPI_API_KEY` / `MLAPI_BASE_URL`=gpt-5-mini, `MLAPI_NANO_BASE_URL`=nano, `GEMINI_API_KEY`).

## 자동 시연 + 화면 녹화

화면 우하단 `▶ 자동 시연 재생` 버튼을 누르면 10개 화면을 자막과 함께 자동으로 순회합니다(`⏸ 정지`로 중단).
관리자 시연 영상은 이렇게 녹화하세요:

1. 브라우저에서 `http://127.0.0.1:8000/ui/#/staff` (또는 `/#/app`)를 전체화면으로 엽니다.
2. **Win + G**(Xbox Game Bar) → 녹화 시작, 또는 **Win + Alt + R**로 바로 녹화 시작/정지.
3. `▶ 자동 시연 재생`을 눌러 하드프리 순회를 녹화하고, 필요하면 중간에 `⏸ 정지` 후 `⚡ 실제 AI` 버튼을 눌러 실제 호출 장면을 담습니다.
4. 녹화본(MP4)은 `영상` 폴더(`%USERPROFILE%\Videos\Captures`)에 저장됩니다.

> 빌드를 새로 했다면 브라우저에서 **Ctrl + F5**(강력 새로고침)로 최신 번들을 불러오세요.

## 아키텍처 메모

- **판정 결과(고객 수용 / 일부 수용 / 기각)** 는 LLM이 아니라 **협상 과정에서 사람(담당자)이 결정**하는
  값입니다. AI 산출물(위반/미이행/… 규정 판정)·AI 신뢰도 검증(PASS/ESCALATE/BLOCK)과 분리해
  `decision.decided_by = "담당자"` 로 표기합니다.
- **일관성 점수** 는 과거 결정 대비 이번 결정의 정합도를 나타내는 **파생 지표**입니다.
- 스택: Vite 5 + React 18 + react-router(HashRouter). 빌드 산출물은 `base: '/ui/'`.
