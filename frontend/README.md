# 금융 민원 처리 — 프론트엔드 (React SPA)

기존 FastAPI 백엔드(`complaint_processing/api.py`)를 **시각화**하는 시연용 프론트엔드입니다.
백엔드 로직은 전혀 바꾸지 않고, 화면에서 새로 도출된 기능(사건 목록·일관성 점수·판정
결과·마이페이지 등)은 백엔드에 얇은 시연 계층(`demo_store.py` / `demo_api.py`)으로만 추가했습니다.

사용자는 **민원인**과 **기관 직원** 둘뿐입니다. 첫 화면(`/`)에서 어느 쪽으로 들어갈지 고릅니다.

- **직원 포털** — 업무 요약 · 사건접수 · 처리현황 · 협상·중재 · 고객 이력 · 마이페이지 (좌측 사이드바)
- **민원인 포털** — 홈 · 민원접수 · 진행현황 · 이력 · 마이페이지 (상단 탭) + 진행현황에서 들어가는 협상·중재 화면

협상·중재는 **직원 포털의 콘솔 한 곳**에서만 진행합니다(개시·발언 진행). 처리현황은 상태 요약과
콘솔 링크만, 민원인 포털은 진행현황의 진입 카드 하나만 갖습니다 — 같은 기능이 여러 화면에
흩어져 있던 것을 정리한 구조입니다.

## 시연 실행 (빌드본 — 권장)

빌드 산출물(`complaint_processing/ui/`)이 저장소에 포함되어 있어, **백엔드만 켜면** 바로 열립니다.

```bash
# 저장소 상위(Downloads)에서
python -m uvicorn complaint_processing.api:app --port 8000
```

브라우저에서 접속:

| 화면 | URL |
| --- | --- |
| 시작(선택) | http://127.0.0.1:8000/ui/ |
| 직원 대시보드 | http://127.0.0.1:8000/ui/#/staff |
| 민원인 앱 | http://127.0.0.1:8000/ui/#/app |

> 라이브 API 호출(`/api/*`)이 실패하면 화면은 내장 폴백 데이터로 자동 렌더링됩니다.

## 개발 (핫리로드)

```bash
# 1) 백엔드 (한 터미널)
python -m uvicorn complaint_processing.api:app --port 8000

# 2) 프론트 (다른 터미널)
cd frontend
npm install
npm run dev          # http://localhost:5173/ui/  (/api → 8000 프록시)
```

## 빌드 (배포/시연본 갱신)

```bash
cd frontend
npm run build        # → complaint_processing/ui/ 로 출력
```

빌드 후 uvicorn을 (재)시작하면 FastAPI가 `/ui` 로 서빙합니다.

## AI가 실제로 도는 지점

목록·이력은 DB 실측값으로 즉시 렌더하고, 아래 지점에서만 실제 LLM 파이프라인을 호출합니다.
화면에는 모델 이름·소요 시간 같은 내부 정보를 노출하지 않습니다(사용자는 개발자가 아닙니다).
호출 모델은 `frontend/src/api.js` 의 `MODEL` 과 백엔드 기본값으로 고정합니다.

- **사건접수** → `AI 검토계획 세우기` : 접수 내용을 코퍼스에 질의해 검토 항목을 도출
- **처리현황** → `AI 판정 생성` · 유사 과거사례 검색 · `안내문 생성`(민원인용/내부·감독기관용 분리 작문)
- **협상·중재** → `협상·중재 열기` · `다음 발언 진행` : 양측 롤플레이로 쟁점 원장을 채움
- **민원접수(민원인)** → `쟁점 확인하기` : 자연어 사실관계에서 검토 쟁점을 뽑아 확인·보정

> ⚠️ **왜 버튼 단위 호출인가**: GPT-5 계열은 reasoning 모델이라 구조화 호출 1건이 ~20초.
> 전체 파이프라인을 한 번에 돌리면 5~10분이 걸립니다. 그래서 화면은 DB 값으로 즉시 렌더하고,
> 버튼을 눌렀을 때만 해당 영역을 실제 LLM으로 채웁니다.
> 실제 LLM 키는 `.env`(`MLAPI_API_KEY` / `MLAPI_BASE_URL`=gpt-5-mini, `MLAPI_NANO_BASE_URL`=nano, `GEMINI_API_KEY`).

## 화면 녹화

1. 브라우저에서 `http://127.0.0.1:8000/ui/`를 전체화면으로 엽니다.
2. **Win + G**(Xbox Game Bar) → 녹화 시작, 또는 **Win + Alt + R**로 바로 녹화 시작/정지.
3. 녹화본(MP4)은 `영상` 폴더(`%USERPROFILE%\Videos\Captures`)에 저장됩니다.

> 빌드를 새로 했다면 브라우저에서 **Ctrl + F5**(강력 새로고침)로 최신 번들을 불러오세요.

## 아키텍처 메모

- **판정 결과(고객 수용 / 일부 수용 / 기각)** 는 LLM이 아니라 **협상 과정에서 사람(담당자)이 결정**하는
  값입니다. AI 산출물(위반/미이행/… 규정 판정)·AI 신뢰도 검증과 분리해 표기합니다.
- **AI 신뢰도 검증** 코드값은 `PASS`/`ESCALATE`/`BLOCK` 이지만, 화면 라벨은
  `근거 확인`/`확인 필요`/`근거 부족` 입니다(`demo_store.CRITIC_BADGES` 가 단일 진실 원천).
- 스택: Vite 5 + React 18 + react-router(HashRouter). 빌드 산출물은 `base: '/ui/'`.
